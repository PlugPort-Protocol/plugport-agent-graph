MCP Client
1Build the MCP package

Clone the repo and build once. Subsequent runs rebuild automatically.

bash
git clone https://github.com/PlugPort-Protocol/plugport-agent-graph.git
cd plugport-agent-graph
pnpm install
pnpm --filter @pag/core build
pnpm --filter @pag/mcp build
2Edit Claude Desktop config

Open ~/Library/Application Support/Claude/claude_desktop_config.json (create it if it doesn't exist) and merge in the following. Replace the args path with the absolute path on your machine.

json
{
  "mcpServers": {
    "plugport-agent-graph": {
      "command": "node",
      "args": ["/path/to/plugport-agent-graph/packages/mcp/dist/index.js"],
      "env": {
          "PLUGPORT_URL": "https://testnet.plugport.wtf",
          "PLUGPORT_API_KEY": "pp_your_key_here",
          "PAG_GRAPH": "default",
          "MONAD_RPC_URL": "https://testnet-rpc.monad.xyz",
          "ANCHOR_CONTRACT": "0x12a49Ee0c56dA65Eb519cC612Ee4D3A4A089c1f4",
          "ANCHOR_PRIVATE_KEY": "0x...",
          "EXPLORER_TX_URL": "https://testnet.monadscan.com/tx/"
    }
    }
  }
}
3Restart Claude Desktop

Fully quit and reopen Claude Desktop. You should see plugport-agent-graph listed under connected MCP servers in the settings panel. Try: "Remember that our API runs on port 8080."
